# astropng-core

Shared core for the AstroPNG family of ports — the same XISF/FITS → PNG
converter reimplemented in [Rust](https://github.com/peterbuitho/xisf2png),
[Go](https://github.com/peterbuitho/AstroGoPNG),
[Nim](https://github.com/peterbuitho/AstroNimPNG),
[Zig](https://github.com/peterbuitho/Astro2PNG), and
[Scala/JVM](https://github.com/peterbuitho/AstroScalaPNG).

Instead of hand-porting XISF/FITS parsing, the min/max stretch, resize +
label stamping, WCS math, and SIMBAD/CDS Sesame catalogue lookup into every
language, this crate holds that logic once and exposes it two ways:

- **As a normal Rust crate** — for the Rust `xisf2png` app, which depends on
  it directly and calls the safe API in [`batch`](src/batch.rs).
- **As a C ABI** (`src/ffi.rs`, `include/astropng_core.h`, generated by
  [cbindgen](https://github.com/mozilla/cbindgen)) — for every other
  language, which links against `libastropng_core.{so,dylib,dll}` (dynamic)
  or `.a`/`.lib` (static) and calls `astropng_run`.

Each language's app keeps only what's genuinely language- or
platform-specific: CLI argument parsing, the GUI, OS shell integration, and
packaging.

## API shape

Deliberately minimal — one call, matching how every existing CLI/GUI already
uses this logic (they never touch XISF/FITS parsing or SIMBAD lookup
individually, only the end-to-end batch run):

```c
int32_t astropng_run(const AstropngOptions *opts,
                      const AstropngCancelToken *cancel,   // nullable
                      AstropngProgressCallback callback,
                      void *user_data,
                      AstropngSummary **out_summary,
                      char **out_error);
```

See [`include/astropng_core.h`](include/astropng_core.h) for the full
surface (`AstropngOptions`, `AstropngProgress`, `AstropngSummary`,
cancellation, and the two `_free` functions callers must use to release
memory this crate allocated). [`examples/smoke.c`](examples/smoke.c) is a
minimal end-to-end usage example.

## Building

```sh
cargo build --release          # produces target/release/libastropng_core.{so,a}
cbindgen --config cbindgen.toml --output include/astropng_core.h   # after changing ffi.rs
```

The generated header is committed so consumers without a Rust toolchain
(most of the other language ports, in CI) don't need one just to get the
function signatures.

## Status

First slice: core extracted from `xisf2png`, C ABI designed and smoke-tested
from C. The Rust `xisf2png` app is being migrated to depend on this crate.
Go/Nim/Zig/Scala ports migrating to call the C ABI are follow-up work, one
language at a time.
